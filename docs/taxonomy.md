# Taxonomy

The standard ids used in VIDEO.md version 1. Ids outside these lists start with `x-` (see [specification](spec.md), section 9).

## Production method

Used as `made_mix` keys, `inferred.made`, `inferred.alternatives` keys, and in parentheses after `made~`. It describes how the base picture of a shot was made, not the overlays on top.

| Id | Meaning |
|---|---|
| `live_action` | Filmed with a camera |
| `ai_video` | Generated by a video model |
| `avatar` | A digital human / talking avatar |
| `cg_3d` | 3D rendered |
| `code_render` | Rendered from code or a template (motion graphics, slides, data charts) |
| `screen_capture` | A screen recording or screenshot |
| `still_motion` | A still image with zoom or pan |
| `static_hold` | A still image held without motion |
| `anim_2d` | 2D animation |
| `stop_motion` | Stop-motion animation |
| `film_footage` | Footage from films or TV |

## Camera

Used as `camera` in shot files.

| Id | Meaning |
|---|---|
| `static` | Fixed camera |
| `static_with_subject_motion` | Fixed camera, the subject moves |
| `planar_zoom_pan` | The whole picture zooms or pans as a flat image |
| `handheld_like` | Handheld shake |
| `smooth_move` | Smooth camera movement (dolly, gimbal, crane) |
| `unknown` | Not measured |

## Overlays

Used in `overlays` in shot files. This list is open: producers MAY add ids without `x-`, and readers MUST accept ids they do not know.

| Id | Meaning |
|---|---|
| `subtitle` | Subtitles that follow the speech |
| `title` | A title |
| `label` | A short text label pointing at something |
| `styled_text` | Decorated, animated text for emphasis |
| `static_graphic` | A static graphic laid on top |
| `layout_template` | A layout frame around the picture |
| `animated_sticker` | An animated sticker |
| `static_sticker` | A static sticker |
| `pip` | Picture-in-picture |

## Readers and `decided_by`

| Id | Meaning |
|---|---|
| `tools` | Measurements and rules only |
| `model` | An image or video model looked at the shot |
| `agent` | An agent looked at the frames and reviewed the verdict |
| `human` | A person corrected or confirmed it |

## Flags

| Id | Meaning |
|---|---|
| `uncertain` | The evidence cannot tell two methods apart; needs a look |
| `disputed` | Two readers disagree |
| `low_confidence` | The probability of the verdict is low |
